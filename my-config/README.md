# Personal OpenClash configuration

This directory is maintained by NeoHeee on the `custom` branch.

- `rules/direct.list`: personal direct-domain rules.
- `rules/proxy.list`: personal proxy-domain rules.
- `rules/reject.list`: personal blocking-domain rules.
- `yaml/`: optional generated/validated OpenClash configurations.

The lists below are initially examples only, **not automatically loaded** by OpenClash.
Do not insert private node subscriptions, credentials, or tokens in this public repository.

Use `custom` for personal changes; `upstream-sync` is a clean tracking branch.
The sync workflow is stored on `main` so the schedule works without changing the default branch.
If a merge conflict occurs, the custom branch is not force-overwritten.
